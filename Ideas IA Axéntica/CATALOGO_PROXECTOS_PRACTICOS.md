# Catálogo editable de proxectos prácticos

Propostas para o curso **«Iniciación á IA Axéntica»**. Cada proxecto debe realizarse coa colaboración dun sistema conversacional dentro dun espazo de proxecto, con fontes autorizadas, límites claros e revisión humana.

**Lenda de recursos:** 🗂 documentos · 📊 CSV/datos públicos · 🧩 HTML local · 🔎 busca/fontes · 🖼️ imaxe · 🔊 audio · 🗺️ API pública

## Criterio común para seleccionar ou adaptar un proxecto

Cada proposta debe poder definirse como:

```text
Finalidade + fontes + accións autorizadas + revisión humana
```

O produto final irá acompañado dunha ficha de deseño: obxectivo, fontes permitidas, accións autorizadas, accións que requiren consulta, criterios de validación e riscos ou límites de uso.
